# Graphify

Architecture visualization tool used at the start of the development workflow.

## Purpose

Maps the entire application's:
- Function relationships
- Tool invocations
- Architecture overview

## Usage in Workflow

Used as the first step in the [[Development Workflow Pattern]] to understand the codebase before making changes.

## Why It Matters

- Provides visual context for complex codebases
- Helps identify dependencies before modifying code
- Reduces "fix A, break B" risk by understanding the full picture
